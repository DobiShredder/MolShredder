# Synthetic contour fixture

`contour.pdb` holds three synthetic atoms. `contour.ccp4` is a 12×18×17 Gaussian density map of those atoms
(0.5 Å spacing, 3 Å buffer) generated with Open-Source PyMOL 3.1.0 `map_new` and saved as CCP4 with an identity
skew record. Neither file contains experimental or licensed data. Expected PyMOL contour behavior is recorded in
the SEQ-311 S5 reference capture.
