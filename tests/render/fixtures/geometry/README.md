# Geometry parity fixtures

- `benzene.mol`: synthetic Kekulé benzene written for MolShredder (ideal hexagon, C–C 1.40 Å, C–H 1.09 Å). No external data.
- `pymol310_primitives.json`: sphere and cylinder primitives exported as VRML by Open-Source PyMOL 3.1.0 (Homebrew,
  macOS arm64) from `tests/io/fixtures/1ubq.pdb` and `benzene.mol`, with an identity view so coordinates are model
  coordinates, plus ray-image center-pixel alpha for transparency settings. Generated by the black-box capture recorded in
  the work_home research session `pymol-geometry-primitives-blackbox_20261004T000000Z`; it contains numbers only and no
  PyMOL code.

`tests/render/geometry_parity_test.py` runs `molshredder_geometry_probe` and compares primitives within 5e-3 Å/RGB after
merging collinear same-style segments (PyMOL exports one cylinder for same-colored half-bonds).
- `pymol310_backbone.json.gz`: cartoon triangles (vertices rounded to 0.01 Å, per-vertex colors) and ribbon cylinders exported as VRML
  by the same PyMOL build from `1ubq.pdb` and its copy without residues 30–32 (header kept). Recorded in the research session
  `pymol-cartoon-ribbon-blackbox_20261004T020000Z`; numbers only. `tests/render/backbone_parity_test.py` compares meshes by two-way
  point-to-triangle distance, triangle count and vertex colors.
- `pymol310_backbone_styles.json.gz`: the same 1ubq capture for the dumbbell and putty profiles (`cartoon dumbbell/putty` plus
  `cartoon_dumbbell_*` and `cartoon_putty_*` variants) and the flag settings `cartoon_flat_sheets`, `cartoon_smooth_loops`
  (+`_first/_last/_cycles`), `cartoon_fancy_helices`, `cartoon_fancy_sheets`. Black-box VRML exports from the same PyMOL build; numbers
  only. The engine was written from these captures and the read-only pinned source's observable behavior (no code copied).
  `backbone_parity_test.py` compares them with the same two-way mesh distance.
- `pymol310_measure.json`: distance/angle/dihedral dash cylinders exported as VRML by the same PyMOL build from `1ubq.pdb` (labels
  hidden, identity view) for default, `dash_length/dash_gap`, `angle_size/dihedral_size`, solid (`dash_gap 0`) and `dash_width`
  variants. Research session `pymol-measurement-blackbox_20261004T040000Z`; numbers only. `tests/render/measure_parity_test.py`
  matches every MolShredder overlay segment to a PyMOL dash within 5e-3 A.
- `pymol310_contour.json`: `isomesh` segments, `isosurface` triangles and `isodot` dots of the S5 synthetic map (`tests/render/fixtures/contour`) at
  levels 0.5 and 2.0 plus carve 1.5 and buffer 1.0 around atom `C1` exported as VRML (identity view set after the contour objects exist, which yields model coordinates). Research session `pymol-contour-geometry-blackbox_20261004T060000Z` and
  `pymol-isosurface-table-blackbox_20261004T080000Z`; numbers only. `tests/render/contour_parity_test.py` requires identical triangle, segment
  and dot sets within 5e-3 A.
